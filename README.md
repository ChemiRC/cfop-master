# CFOP Master

Herramienta técnica de referencia visual e interactiva 3D para el método **CFOP** (*Cross, F2L, OLL, PLL*) y notación estándar WCA.

## Stack Técnico

- **UI:** React 18 + TypeScript + Vite + Tailwind CSS (`Plus Jakarta Sans` + `JetBrains Mono`)
- **Motor 3D:** `cubing.js` (`<twisty-player>`) con arquitectura de contexto WebGL único + previsualizaciones vectoriales SVG nativas.
- **Atajos del Viewport:** `Space` (Play/Pausa), `←` / `→` (Paso a paso), `R` (Reset).

## Comandos

```bash
npm install
npm run dev
npm run build
```
